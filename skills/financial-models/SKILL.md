# Financial models

Identify the decision, model horizon, currency/units, timing basis and scenario variables. Separate source facts, assumptions, calculated outputs and any external rates with dates. Use current authoritative evidence for time-sensitive financial claims; do not present an illustrative model as personalized regulated advice.

Keep assumptions editable and formulas traceable through the host spreadsheet tools. Distinguish cash flow, revenue recognition, margin and cumulative balances where the model requires them. Avoid hard-coded calculated totals and check signs, periods and conversion factors.

Create a base case and meaningful sensitivities/downside conditions. Recalculate and reopen the saved workbook; reconcile key totals, formula ranges and a hand/independent calculation. Inspect charts/tables and how missing or extreme inputs affect the decision.

Return the editable workbook, source/assumption map, scenarios and verified outputs. Stop at missing material financial assumptions or unsupported recalculation; state the decision limits. A plausible formatted table or cached value alone does not establish a functioning model.
