# Project memory

Recall focused facts before making a consequential project decision when retained context could change it. Select the canonical project or separately selected shared-preference scope explicitly; linked worktrees and unrelated clones must not be conflated. Search narrowly, inspect coverage and expand only useful source-linked hits. Distinguish no match, incomplete indexing, stale source, conflict and unavailable evidence.

Verify current instructions, source revision, validity and applicability before relying on a fact. A similarity score is not factual authority. Keep temporary task history in the existing task record when one is needed; do not turn an entire transcript or unreviewed retrieval into durable memory.

Save stable, verified decisions with source identity, scope and currentness. Correct or supersede the owning fact rather than accumulating contradictory copies. Use the actual prepare/commit and revision checks exposed by the runtime. After uncertainty, reconcile the original operation identity before another mutation. Forgetting is explicit and includes managed recovery copies; restoring old data must not resurrect known forgotten facts.

Return compact relevant context, source locators and coverage gaps. Stop reliance on a critical fact when its source or current validity cannot be checked, and state the resulting decision limit. Do not claim complete recall from a successful search.
