# Paged document artifacts

Select the project-installed document/format commands through pi bash and inspect their actual capabilities. Mirket does not supply an Office, general PDF or OCR engine. Preserve the original source and distinguish editable source, visual export and extraction-only output.

Inspect source structure, pages, tables, images and fonts before a fidelity-sensitive edit. Use the appropriate host format workflow; complex scans or uncertain extraction require explicit source-linked uncertainty. Do not infer text accuracy or table structure from a successful extraction alone.

Save and reopen the deliverable, render every relevant page and inspect the saved result for clipping, wrapping, pagination, headers/footers, table flow, glyphs and source fidelity. Verify material claims, numbers and citations against originals. A render or hash alone does not prove semantic correctness or editability.

Return the editable/source artifact, requested export, page evidence and unsupported/untested features. Unless the task sets another budget, share 30 minutes and three final repairs across paged production and review, with one target repair; combined motion work uses 45 minutes/four, not an added budget. Stop at that limit or a concrete host capability gap; preserve sources and report unresolved defects. Restricted Anthropic DOCX instructions remain link-only and are not an execution prerequisite.
