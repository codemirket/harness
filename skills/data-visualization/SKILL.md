# Data visualization

Identify the comparison or decision the viewer needs to make. Audit the source grain, denominators, units, missingness, transformation and date range before selecting an encoding. Keep calculated values reproducible and traceable to the supplied data.

Choose position/length and scale to support accurate comparison; use color, area and annotation deliberately. Make normalization, truncation, logarithmic axes, uncertainty and excluded observations explicit when used. Do not turn absent data into zeros or imply a causal effect from a descriptive chart.

Use the suitable host plotting/authoring tools. For scientific or shareable figures, deliver a standalone artifact and editable source. Inspect the saved chart at its intended size for labels, legends, contrast, clipping, locale and accessibility; verify plotted points/totals against an independent source-data sample.

Return the chart, underlying data/transformation, units and interpretive limits. Stop when the visual answers the stated question and its numerical/visual checks pass, or report the missing denominator/source evidence that prevents a trustworthy plot.
