# Editable local design documents

Use this reference when the chosen route is Mirket's optional local Penpot
package for UI design files, structured layouts and handoff. Preserve the user's
chosen editor and requested portable format when another available workflow
supports them; a local service handle alone does not fulfill a portable-file
request. Inkscape supports SVG illustration; website implementation stays with
the project's frontend/browser workflow.

Inspect `mirket package status` and `mirket package probe PACKAGE --schemas
--project /absolute/project` before promising a deliverable. Selection installs
no model or paid service. The first verified adapter target is macOS ARM64.
Penpot needs its local service profile started through `mirket package start
penpot`; an active headless browser loads the real editor and a fixed typed
plugin. Its native editable design stays in the local service; a scoped project
handle identifies the saved file. Export the native file when the verified tool
contract supports the requested portable format.

Compose with actual copy, reading order, typography roles, space and palette.
Read the create tool's schema and use only properties that its saved-file profile
can preserve. Keep the editable document/handle separate from PNG/SVG exports.
Unsupported features are errors to resolve, not permission to flatten the whole
design or silently substitute another editor.

Inspect the saved document's IDs, geometry, text and relationships; refine using
those handles, then reopen and export the saved result again. Rendered previews
must be inspected at intended size and focal detail for hierarchy, text fit,
clipping and consistency. A successful save or export is not visual acceptance.

Project-scoped paths and explicit overwrite intent apply to local artifacts.
Penpot edits also persist in a local server; cancellation cannot undo an edit
already saved. Keep service credentials outside project source.
Report the inspected document, exports and unsupported or unverified behavior.
