# OpenPencil design source

Use `runtime_status` to verify the configured Mirket editable-file capability and select the project explicitly. Read [file authoring](references/file-authoring.md) before creating a scene or planning a patch; it maps the current typed operations and layout limits. Use the active tool schema if it differs. Do not attach to the user's normal editor or install the upstream CLI/MCP server.

Inspect the selected source or a minimal native specimen before expanding it. Record the source revision, named target paths, intended changes and export target. Keep unrelated nodes and original source intact; prepare revision-bound operations to new destinations. An arbitrary Figma `.fig` file may contain unsupported features: preserve it and report a refusal instead of stripping features to force an import.

Represent supported frames, components and single-line text as editable nodes. Let a fixed horizontal or vertical container own its children's positions; change its gap, padding and alignment instead of placing layout children manually. Check both axes with real content before export. Keep sibling names unique so patch paths remain unambiguous. Native components in this subset do not imply linked instances or variants. When tokens are required, compile and consume their resolved values; do not claim unsupported variable bindings.

Save, reopen the saved file and make a representative text/layout or component change through the file workflow. Export the changed target and inspect saved pixels for actual glyphs, clipping, spacing, contrast and intended dimensions. Stress affected fixed text boxes with the longest required label and affected containers with the narrowest required width. The runtime does not measure or shape text; a successful geometry check cannot establish that the label fits. Export references regular Noto Sans: verify the renderer's font and rights rather than assuming a font is embedded. A file extension, node count or successful receipt does not prove editability or visual quality.

Return the editable source, checked exports, before/after revisions and named target, observed reopen/change result, pixel inspection and unsupported features. Distinguish file-workflow evidence from native editor fidelity and live responsive/accessibility/interaction evidence. Unless the task sets another budget, share 15 minutes/two final repairs for static or vector work and 30 minutes/three for interface or paged designs, with one target repair; combined work uses the largest applicable limit. Stop when the required structure and export are verified or report unresolved defects at the limit. If the capability, font or requested feature is unavailable, preserve source and report the gap.
