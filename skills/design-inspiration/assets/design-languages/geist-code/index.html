Guides / Jobs / Retry policy

Change the attempt limit

Allow a sample job up to three total attempts. Keep the initial attempt distinct from the retries, and inspect the changed line before using the configuration.

3Total attempts in the sample policy.

Three attempts means one initial attempt and up to two retries. Retry only an operation that can be safely repeated. This fictional snippet is explanatory and is not run here.

The configuration change

Only the attempt limit changes. The backoffMs value stays at 1000 milliseconds.

Know what this snippet leaves out

Read the implementation questions before adapting

A real runner needs an error policy, idempotency, cancellation, timeout and queue behavior. The example does not implement those contracts. It is not a configuration for an existing package.
