Why the direction changes selectively

Purposeful version: layout and the summary arrow follow the reading direction. The clock, checkmark, email and case reference retain their meaning and orientation.

Switch to English and back. The same case, customer, note draft and saved note stay attached to SUP-2047. Clear the note and save to inspect rejection, then correct it. Mixed names use bdi; known Latin identifiers use dir="ltr".

This is a limited Arabic layout preview, not reviewed Arabic localization. No screen reader or native device was tested. Open the polished wrong version to inspect universal mirroring, then return to the purposeful version.
