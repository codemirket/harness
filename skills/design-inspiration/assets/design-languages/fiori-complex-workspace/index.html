Design-language study: Complex object continuity

Original fictional identity and content. The three linked panes represent an order collection, one parent order, and one child item. This page has no backend or durable storage.

Purposeful. Stable object/item IDs locate the current work. Apply stages one child; Save records the parent locally. Interruption can preserve the draft, and an order-level failure links back to its item.

Attractive wrong. The tidy workspace announces an applied child as “Saved” while the parent still has an unrecorded draft. Green reassurance collapses two different transaction boundaries.
