# Content and search

Identify the audience question, user intent and page's place in the information architecture. Inspect existing content, internal links and available search/usage evidence. Verify current search behavior through qualified browsing when it matters; rankings are observations tied to date/context, not guarantees.

Resolve duplication, missing answers and confusing structure before adding keywords. Use descriptive titles/headings, accessible content and links that help the reader complete the task. Preserve accurate claims, canonical identity and relevant source attribution. Do not invent traffic figures or optimize for a metric the project does not observe.

Implement the bounded page/content change when requested and inspect the saved/live result. Check metadata, crawlable navigation and intended links with actual project capabilities. Separate implemented changes from future measurement and uncertain search-engine response.

Return the intent/structure decision, changed content and verification/measurement plan. Stop when the page serves the stated intent and checks pass; report unavailable analytics/indexing evidence. No ranking guarantee, content farm, paid campaign or external publication is implied.
