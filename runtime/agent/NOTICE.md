# Mirket agent-runtime 0.0.3 notices

The 0.0.3 agent-runtime package is a native Rust runtime. Its durable fact
store and execution journal are implemented by Mirket and use the pinned Rust
and SQLite dependency closure described by the release notice. The contained
embedding helper uses `fastembed-rs 7.2.0`, ONNX Runtime `1.31.0`, and the
multilingual MiniLM model manifest in `model.json`. The helper receives the
native ONNX libraries listed in `native.json`; it does not install Python or
download models while serving.

The MiniLM model remains under its upstream Apache-2.0 terms. FastEmbed and
ONNX Runtime retain their upstream licenses and notices. The exact native
library hashes and the model revision are part of the package identity. The
Rust distribution notice generated by the release owner covers Rust crates and
their declared licenses; it is shipped beside the executable.

No Mem0, Qdrant, LangGraph, spaCy, Python FastEmbed distribution, hosted
service, provider credential or runtime model downloader is included in this
package. Historical review reports may mention those superseded components;
those reports are evidence of earlier releases and are not package contents or
current runtime contracts.
