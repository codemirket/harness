A small set of useful capabilities.

Selected, not automatic

Scoped memory

Local SQLite facts with sources, corrections, expiry and forgetting. Project or shared scope; no passive transcript harvesting.

Code navigation

JavaScript and TypeScript definitions and references over selected, revision-bound sources. No implicit project execution.

Editable design

Tokens, SVG exports and D2 diagrams. Keep the source; inspect the pixels. OpenPencil is separately configured.

Finite video

HyperFrames from local HTML, CSS and assets, with supplied audio and captions. Chrome requires an explicit setup choice.

Focused guidance

Native Pi skills and profiles for concrete workflows. Choose what helps; leave project builds and exports with project tools.

Bounded coordination

Optional Pi children with independent assignments and disjoint ownership. Your model choices stay in charge.

Installation guide ↗Browse release assets ↗
  1. 01

    Download & verify

    Use the listed release assets and check SHA256SUMS before running the installer.

  2. 02

    Install with your settings intact

    Follow the guide for fresh setup or migration. Preserve authentication, sessions and unrelated settings.

  3. 03

    Check the actual runtime

    Ask Pi to run mirket_doctor, then use /mirket doctor. Select optional tools through /mirket setup.

Evidence, not blanket promises.

v0.0.1 was qualified on macOS 26.5.2 ARM64. The macOS 26.0+ installation floor is not qualification for macOS 27 or other platforms. Mirket processes are not an OS sandbox. Tool readiness is not output quality.
