02 / The working layer

Context that lasts.
Tools with a purpose.

Use the capability the task needs.

01

Remember deliberately.

Canonical SQLite facts with project or shared scope, sources, corrections, expiry and forgetting. Local semantic retrieval loads when needed.

No passive transcript harvesting.

02

Navigate selected code.

Inspect JavaScript and TypeScript, definitions and references over explicit, revision-bound source snapshots.

No implicit project discovery or execution.

03

Make editable design.

Design tokens, SVG/vector exports and D2 diagrams. Keep editable source and inspect the rendered result.

OpenPencil is separately configured; Raster/Sharp is excluded.

04

Produce finite video.

HyperFrames turns local HTML, CSS, JavaScript and selected assets into video, with supplied audio and captions.

Verified FFmpeg/ffprobe; Chrome is an explicit setup choice.

05

Choose useful guidance.

Selected native Pi skills and profiles bring relevant workflows and safeguards into the task. Guidance earns its place through evidence.

Project builds and exports stay with project tools.

06

Coordinate bounded work.

Optional Pi CLI children take useful independent assignments with disjoint ownership. The lead integrates their actual output.

The user’s model and reasoning choices stay in charge.
