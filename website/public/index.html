GOOD TO KNOW

Fits your environment.

What changes on my device?

Setup installs a managed Mirket executable, shared instructions, skills and local MCP connections for the hosts you select. It preserves unrelated configuration and stops on conflicting managed edits. Start a fresh host session to load the new tools.

Can I use it with an existing project?

Yes. Your agent can inspect the project and select useful expertise. Project setup records those selections and installs their guidance. Installing Mirket does not automatically rewrite application code.

Does it replace my agent or subscription?

No. Keep Codex or Claude and your existing authentication. The harness and task state run locally; inference uses your configured providers, which may be remote. Their usage limits and billing still apply.

Does it guarantee better results?

No harness can guarantee correctness. Mirket makes guidance, tool scope and evidence explicit. Its checks can validate records and file identity; real tests and human judgment still determine whether the work is right.
