A few useful details.

Does Mirket replace Codex or Claude?

No. It installs shared guidance and MCP connections into supported hosts. The host retains permissions, authentication and its session lifecycle.

Do I need the entire design stack?

No. The Rust CLI and expertise catalog work independently. Select the design package only when you need its rendering, canvas and media tools.

Does local mean inference stays on my device?

The harness and its state run locally. Model inference uses your authenticated targets, which may be remote providers or a local daemon. Your provider's data and billing policies still apply.

Can I use it with an existing project?

Yes. Mirket can adopt an existing project and install selected expertise. Setup preserves unrelated client configuration and checks managed files for drift. Your project's instructions govern the work.
