OPTIONAL / AGENT RUNTIME

Pick up the thread.

The optional agent runtime uses Mem0 for chosen project facts and LangGraph for durable worker checkpoints. Chat history is not automatically ingested.

Memory & recovery ↗
What gets backed up?

Durable-state backups cover records, memory and checkpoints. Project files, credentials and desktop settings need separate backups. Uncertain external effects are not blindly replayed.

Optional packages require a supported private Podman environment with Linux ARM64 containers. Check supported targets ↗

mirket project plan --project /absolute/project
mirket project sync --project /absolute/project

What changes on my device?

Setup installs a managed executable, shared instructions, skills and MCP configuration for selected hosts. It preserves unrelated settings and stops on conflicting managed edits. Optional packages stay opt-in.

Does Mirket guarantee correct results?

No. It supplies methods, scoped tools and inspectable evidence. Real tests, artifact inspection and human judgment determine whether the work is right.
