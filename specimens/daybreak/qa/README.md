# Daybreak export regression checks

Run the frozen artifact check with explicitly selected executables:

```sh
/absolute/private/node specimens/daybreak/qa/check-export.mjs /absolute/private/ffmpeg /absolute/path/to/daybreak.mp4
```

These checks cover two demonstrated defects and a prior regression: missing
opening glyph ink, hero CTA/wordmark separation, and a full-height exposed stage
gutter. They are specific to this artwork, font, time, and 1280×720 profile.
They do not certify overall design quality or every possible missing pixel.

`intro-unmasked-control.png` is an independent counterfactual generated by
copying the final composition and changing only the opening word's reveal
`clipPath` values to `none`, then exporting with the same Mirket private
Chrome/HyperFrames/FFmpeg route and decoding at 0.7 seconds. It is not a crop
of the candidate or a model-authored expected picture. All original asset
rights are unchanged; the image contains the admitted Noto Sans wordmark.

The initial defective export fails both letter probes (zero painted pixels)
and the hero separation check. The repaired export passes; the unmasked
control has 285/83 lime pixels in the y/k probe regions versus 283/80 in the
candidate, allowing encoding edge differences without changing thresholds.
An earlier IAB JPEG screenshot was an unsuitable exact raster oracle for the
private video renderer; that failed comparison is retained in private evidence.
The same-browser masked/unmasked pair independently has zero changed pixels
after repair, versus 1084 before repair at the stated difference tolerance.
