# Retired capability evidence

The current product boundary is in the [approved implementation plan](../planning/implementation-plan.md).
On 2026-10-28, obsolete contracts, unselected admissions and their historical
notice bundles were removed from the working tree. They describe removed
Mirket general browsing, Python/SQL/PDF/OCR and broad-language navigation,
generic file-range tools, the abandoned Chromium snapshot, or the cancelled Remotion proposal.
They do not authorize those routes or dependencies. Current Chrome for Testing,
HyperFrames, FFmpeg, Sharp, OpenPencil, design notices and their release gates remain.

## Retrieve the original evidence

Every file below is retained byte-for-byte in Git revision
`0c3133fa9735c97ce5cddc13fb0208835304ffa8`, an ancestor of this cleanup. For example:

```sh
git show 0c3133fa9735c97ce5cddc13fb0208835304ffa8:docs/m3-browser-runtime.md
```

Use the table's full path after the colon to inspect any other record. Historical
links now land here rather than implying that removed routes are current.
When an old link named a section, locate that section in the original document.
A verified tar snapshot and SHA-256 inventory also exist in the private cleanup
evidence directory; Git is the portable source of record. Historical notices
remain available there; they are not the notice bundle for current payloads.
Keep full Git history when retrieving this evidence from a shallow checkout.
