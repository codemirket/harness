# Localize a booking interface to Turkish

Translate `en.json` for a professional travel operations
interface in tr-TR. Deliver `tr.json` with exactly the same keys and
`translation-qa.md` explaining terminology, meaning checks and remaining limits.
The fixture is fictional; do not contact a supplier or change a booking.

Preserve booking/name placeholders, ICU variable `count`, the supplied =0/one/other
branches and # substitutions (the application requires this exact message schema),
<strong> markup and the literal timezone identifier Europe/Istanbul. Localize the
number/date presentation for Turkish while retaining the EUR amount, deadline and
qualifications. Follow the cancellation/refund state precisely. Use natural
professional Turkish. Verify all outputs; do not claim a native human or live UI
review unless one actually occurred. Source file is immutable.


Work only in this task directory. Do not install dependencies or contact anyone. Write the requested files and verify them.
