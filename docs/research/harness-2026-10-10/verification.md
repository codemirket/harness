## Defects found and repaired during review

The first full suite found that the rewritten global instructions omitted the
explicit Codex/Claude target statement. It was restored without weakening the
gate. The initial integration also caught a skill payload changed during final
worker edits; the reviewed final bytes were rehashed before installation.

Independent review demonstrated that a naive translation regex accepted an
altered amount, year, day or hour by substring. The repaired fixture checker uses
complete signed numeric tokens and bounded date/time/zone matching. It accepts
normal sentence punctuation and rejects extra or negative amounts. Quote-aware
flat plural checks distinguish ICU literal `'#'` from an active count marker.
Tests emulate a non-UTF-8 default encoding while reading real UTF-8 output.
These are fixture checks, not a general locale or ICU parser.

## Boundaries

These are public development cases with deterministic checks and agent review,
not held-out performance measurements or native-human approval. No live client
activation, native Windows runtime, live ICU/UI, workbook engine, mobile device,
production database or real financial account was exercised in this redesign.
The inherited skills and optional integrations need their own task-specific
runtime and artifact evidence. No comparative intelligence, speed, token savings
or professional certification is claimed.

The standalone skill-creator validator could not run because PyYAML is absent
from the available Python environments. Frontmatter, local references, catalog
hashes, target installation and repository gates were checked independently;
no dependency was installed to conceal that missing optional validator.
