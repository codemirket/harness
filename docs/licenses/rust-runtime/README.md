# Rust crate notice supplements

These exact primary repository license files were omitted from the published
crate archives. `provenance.json` binds each copy to its locked crate checksum,
version, registry source and packaged `.cargo_vcs_info.json` revision, plus the
immutable retrieval URL and notice SHA-256. `mirket dev dist` verifies those
identities before including the unchanged text in `RUST-NOTICES.txt`.

The Rust SDK notice retains its original licensing transition statement and both
license bodies. Cargo metadata declares Apache-2.0; that declaration does not
replace the more specific primary notice. New dependency versions require fresh
source review and explicit provenance updates; distribution never downloads a
replacement notice or substitutes a generic license template.
