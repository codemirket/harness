# 2026-10-27 simplification qualification

This records the accepted simplification pass in the fresh rewrite. The old harness checkout, real `.mirket` installation, Codex settings and public release were untouched. The rewrite source remains uncommitted.

## Changed ownership

| Area | Current implementation |
| --- | --- |
| General file read/edit | Codex and project tools own it. Mirket removed `file_read`, `file_read_ranges`, `artifact_read`, text-replace-copy, `job_result`, the core text adapter and their release payload entries. |
| Memory vectors | SQLite stores normalized blobs; bounded Rust cosine scores eligible current records. The sqlite-vec native build/FFI was removed. Canonical SQLite/FTS, lazy MiniLM and source-linked correction/forgetting remain. |
| Warm semantic model | An idle model retires after 60 seconds; the actual-model and installed two-client checks below measured the effect. |
| Finite jobs | Prepare/start plus `job_status` remain for response-loss reconciliation. A one-call effect would require a separate caller idempotency contract before it could safely replace them. |
| Video adapter | The selected HyperFrames package declares an import API and no package CLI; the current narrow API adapter remains the sole candidate. |
| Skills and platforms | Nine global and 58 project skills remain. Full-catalog integrity/activation screening precedes risk-focused matched outcome trials. Mac ARM64 is the 0.0.1 release target; Windows 11 x64/ARM64 are planned, native-gated targets. |
