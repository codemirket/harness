## Hue: inspectable open-source implementation

[dominikmartn/hue](https://github.com/dominikmartn/hue/tree/a910e31cd24b45b9455c0c3502150413aa5a3b32) was created 2026-04-12; the inspected revision is dated 2026-06-11. GitHub's API returned 850 stars and 67 forks on 2026-10-27. The pinned LICENSE is MIT, copyright Dominik Martin. Metadata and original files are retained privately beside the X capture.

The inspected skill distinguishes values observed in existing components from choices derived for missing components. It compiles a design model and exercises it in previews and product screens; its checks catch token and structural defects. These are useful comparison methods. Its long mandatory sequence, fixed preview templates, display-font bans and home-directory installation defaults are not appropriate blanket Mirket rules. Screenshot-estimated tokens also need explicit uncertainty. We did not install, execute, copy or admit Hue as a runtime dependency. Existing project tokens and components remain authoritative; Hallmark and Taste remain the retained design references.

## Adoption boundary

The new local guidance is original synthesis of these observations, the dated primary articles in [design-harnesses](research-20261027-design-harnesses.md), the contradictory [community discussion](research-20261027-design-community.md), the [showcase methods](research-20261027-design-directions.md), and our own failed video/review trials.
