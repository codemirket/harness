# Private D2 diagram backend admission

This receipt admits only the locally qualified D2 v0.9.0 macOS ARM64 archive
for the rewrite's bounded diagram slice. The source release is pinned to
`d5a51743b6d5c00f1ec6f8340003f5d5a6ba4eda` and the archive is bound by its
SHA-256 in [`m4-d2.manifest.json`](m4-d2.manifest.json). Assembly copies only
the D2 executable, its MPL-2.0 license, and the complete third-party notice
file. It never executes archive scripts, downloads dependencies, or installs
into a host directory.

Assembly also requires the separately supplied, hash-verified `d2.spdx.json`
receipt and copies it to `runtime/d2/d2.spdx.json`. The SPDX file is not in
the upstream release tarball, so treating it as an external input makes its
provenance explicit and prevents an unverified notice from entering a build.

The bundle contains D2's built-in Dagre, ELK and TALA layout engines. The
caller owns process supervision, deadlines, private job directories and
offline policy. This slice provides a typed request/result contract in
`src/diagram.rs`; it does not create a second process owner. The executable
verification path is explicit and hash-bound, with no PATH lookup.

The macOS ARM64 qualification evidence recorded a bounded offline SVG render
for all three layouts, output XML validation, private profile use, no network
handles, clean close/reap, and no execution of upstream helper scripts. The
payload is ad hoc signed and must be signed by the Mirket release process
before public distribution. Windows x64 and Windows ARM64 are recorded as
future candidates only and remain unqualified by this admission.

The SPDX receipt and upstream notices are retained in task evidence. The
SPDX document contains `NOASSERTION` conclusions for some package records, so
the shipped third-party notice remains mandatory and is not replaced by the
SPDX file.
