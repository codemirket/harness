# Private PDF baseline admission

The exact base wheel `pypdf-6.21.2-py3-none-any.whl` is admitted for local integration under the user's rewrite authorization. [The receipt](m3-pypdf.json) binds 407,766 bytes, SHA256 `1d44d1a3a200f25062adff0085b02040e4646431ac2ccac22e42679e91466084`, source commit, dependency metadata, BSD-3-Clause notice and the existing narrow native qualification evidence. It does not admit PDFium or optional crypto, image, font, Brotli or RTL extras. The selected CPython3.13 needs no mandatory third-party dependency for this wheel. No pip or upstream installer runs.

The local baseline passed page selection/order, rotation and metadata preservation plus encrypted, malformed, oversized, existing-destination and source-drift refusal cases on macOS ARM64. Root inspected five original/saved rendered pages. These are task-only baseline results; they do not establish installed-release integration, arbitrary-document fidelity, forms, sanitization, text replacement, Windows execution or a hostile-input sandbox. Recorded upstream advisory ranges exclude this version, including the repeated-missing-object fix in6.21.2; this is not a complete vulnerability guarantee.
