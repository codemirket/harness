The user's full authorization for further rewrite actions covers local integration
of the exact planned SQLGlot 30.24.0 candidate after bounded qualification. The
[artifact inventory](m3-sqlglot.json) retains its exact wheel pin, upstream metadata,
MIT notice and qualification scope. No version, optional extra or installer is
selected implicitly. This is not publication or installed-release approval.

The official pure-Python wheel is 792,162 bytes, SHA-256
`9488828cc018453b7a3ba01e65d2749c9a731314c14583695163ca1f358203fe`.
It has no mandatory third-party dependencies and requires Python 3.9 or newer.
The selected private general Python is admitted separately. Runtime checks bind
the exact wheel before and after work, use isolated Python startup and bound
source bytes, tokens, AST nodes, depth, scopes, pipe output and job duration.
The standard wheel importer is used; this is not protection against a hostile
same-user actor replacing executable files during execution.

The fixed development capability probe passed 23 mandatory checks. The production
leaf passed 58 checks on both the full and selected headless private CPython
3.13.17 candidates. The original failed probe and its narrowly corrected source
annotation are retained in task-state. See the
[qualification note](../../docs/m0-sql-qualification.md) for coverage and limits.

This admission supports explicit offline SQLite/PostgreSQL query and declarative
schema sources. It does not authorize database connections, migrations, project
plugins, template execution, package downloads or a replacement Rust resolver.
Star expansion, JOIN USING, recursive CTEs and DML remain explicitly incomplete
or refused. Windows execution and full release assembly remain unqualified.

The upstream maintainer advisory page reported no published advisories when
checked on 2026-10-25. That observation is not a security certification. Future
updates must retain the license, exact inventory and relevant behavior checks.
