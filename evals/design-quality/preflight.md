# Probe preflight

Run probe compatibility checks before any implementation dispatch. For sealed
cases, the case author runs this and shares its path/hash/status report; the
reference author does not need the hidden brief or probe content.

```sh
node evals/design-quality/preflight.cjs --self-test
node evals/design-quality/preflight.cjs .mirket/study/experiment/hidden/Q01.probe.json
```

The checker uses the current observer's own declaration-prefix validator, so it
does not maintain a second action/locator schema. It accepts project-relative
regular JSON files, refuses symlink components and launches no model or browser.
It executes trusted repository declarations; probe data is never JavaScript.

This control was added after the first study's unnamed table-role locator was
rejected before browser launch. The original plan remains retained. Its uniform
empty-name substring amendment passes the same validator without changing the
observer, expected state or capture slots. The saved checks contain thirteen synthetic
contract probes and the actual rejected/accepted plans; none is a design-quality
score or model execution.

A valid plan can still contain an incorrect expectation or a brittle locator.
Review expectations independently and observe the real effect. Retain failures
and any diagnostic replay; do not weaken the raw requirement or replace a
planned artifact to obtain a passing report.
