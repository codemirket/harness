# Library Hero

Create a website hero illustration for a neighborhood lending library of tools and household objects. Show a person handing a clearly constructed reusable tool case to another person across a counter. Use a restrained cut-paper visual language with warm neutral shapes and forest-green accents. Supply 1600x1000 and a separately art-directed 800x1000 image, plus an integration proof leaving the upper-left region quiet for a headline. No text inside the illustration.
